# Analyze-assembly-line-data
## Goal of the project
Goal of the project was to find the sorce of the problem with productivity, clean and analyze available data and finaly present results and recomendations for improvment.

## Process of the project
First of all first week of available data was analyze in exel 'Analiza danych' to make this step quik and to recognize errors showed in the process. During this analyze three KPI was compare availability, performance, quality. results of this analyze was shown in Powerpoint presentation 'pierwsze spojrzenie'.
Second step based on manualy clean two months of data 'Awarie WORK_SALTED' and 'Zajscia Work_SALTED' and create dashboard in powerBI 'Analiza_liniXvol1' for production department. 
Thirdly raport 'raport_przestojow_linii_X' with analyze and recomendation was introduce to the menagement.
The last but not least during this analyze problem with uncategorized was very often, to avoid this problem in the future console aplication in python was created 'Drzewo-bledu'.
