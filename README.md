# Analyze-assembly-line-data
## Goal of the project
The goal of this project was to identify the source of productivity issues, clean and analyze the available data, and finally present the results together with recommendations for process improvement.

## Process of the project
First, one week of available production data was analyzed in Excel (Analiza danych) in order to quickly understand the process and identify data quality issues. During this stage, three KPIs were compared: availability, performance, and quality. The results of this initial analysis were presented in the PowerPoint presentation pierwsze spojrzenie.

The second step involved manually cleaning two months of production data (Awarie WORK_SALTED and Zajscia WORK_SALTED) and creating a Power BI dashboard (Analiza_liniXvol1) for the production department.

Next, the report raport_przestojow_linii_X, containing analysis results and recommendations, was presented to management.

Last but not least, during the analysis process, a significant issue with uncategorized downtime events was identified. To solve this problem in the future, a Python console application called Drzewo-bledu was created to standardize and categorize downtime records.
